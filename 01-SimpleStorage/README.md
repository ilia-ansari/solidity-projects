# SimpleStorage

A basic Solidity smart contract that demonstrates fundamental concepts.

## Features

- Store and retrieve a favorite number
- Add people with their name and age using a struct
- Keep a list of people using a dynamic array
- Map names to ages using a mapping

## Concepts Covered

- State variables
- Structs
- Arrays
- Mappings
- Functions (`view`)
- Data locations (`calldata`)

## How to Use

1. Deploy the contract on Remix or a testnet
2. Call `store` to save a number
3. Call `retrieve` to read the stored number
4. Call `addPerson` to add a new person

## Tech Stack

- Solidity 0.8.18
- Remix IDE
